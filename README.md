# 台股 ETF 強度檔

把台股掛牌的 ETF 和 0050 放在一起比：報酬有沒有比較多、跌的時候有沒有跌得比較深。

**👉 網站：https://wasai04.github.io/etf-strength-site/**

## 功能

| 分頁 | 看什麼 |
|---|---|
| 總覽 | 選 1／3／5 年或自訂期間，把每檔分成五類，附散布圖和明細表 |
| 空頭 | 2015 年以來 0050 每次大跌時，各檔跌多少、多久回到高點 |
| 觀察 | 幾則看點，按一下直接跳到對應的圖或表（試行中） |
| 說明 | 每一類的定義與資料來源 |

- 門檻都可以用拉桿調整，結果即時更新。
- 可以搜尋代號或名稱，在圖上標出想看的 ETF。
- 「分享目前頁面設定」會複製一條連結，對方打開就是同樣的期間、門檻和篩選。
- 第一次用可以按左上角的「新手導覽」。

## 五類怎麼分

| 類別 | 意思 |
|---|---|
| 穩強 | 報酬比 0050 高，多承受的回撤也划算 |
| 猛強 | 報酬比 0050 高，但多跌的部分不划算 |
| 接近 0050 | 年化和回撤都跟 0050 差不多 |
| 穩但不強 | 報酬比 0050 低，但少跌得更多 |
| 弱 | 報酬比 0050 低，少跌的也補不回來 |

「划算」看的是年化報酬 ÷ 最大回撤（Calmar 比率）有沒有不低於 0050。

另外有三個標記：**靠爆發**（贏 0050 主要靠少數幾段急漲）、**未經空頭驗證**（上市以來沒經歷過大空頭，或長期輸 0050）、**高波動**（大跌時平均比 0050 跌得深）。

## 使用前要知道

- 這是歷史資料，不代表未來，也不是買賣建議。
- 數字的前提是買了就一直持有；中途進出的人，實際報酬可能差很多。
- 只有目前還掛牌的 ETF，已下市的不在裡面。
- 期間愈短，結果愈只代表那段行情。

## 資料來源

證交所 ISIN 名單與開放資料、Yahoo Finance 含息還原價、加權指數（^TWII）。Yahoo 價格裡可疑的日子（暴漲暴跌又回來、超過漲跌幅限制等）會拿證交所、櫃買中心的官方漲跌幅核對，對不上的改用官方的。資料截止日寫在網站上方。

## 本機執行

整個網站只有 `index.html` 和 `data.json`，計算都在瀏覽器裡完成。

```bash
python -m http.server 8765
```

開啟 http://localhost:8765/ 即可。
