# 台股 ETF 強度檔

把台股掛牌的 ETF 和 0050 放在一起比：報酬有沒有比較多、跌的時候有沒有跌得比較深、贏的部分是不是只靠少數幾段急漲。

**網站：https://wasai04.github.io/etf-strength-site/**

## 可以看什麼

- **總覽**：依 1／3／5 年或自訂期間，把每檔 ETF 分成六類（穩強、猛強、爆發型、持平 0050、穩但不強、弱），附散點圖和明細表。門檻可以用拉桿自己調。
- **空頭**：2015 年以來 0050 每一次大跌時，各檔跌了多少、多久回到前高、什麼時候追上或被 0050 追上。
- **觀察**：從這份資料看到的幾件事。
- **說明**：每一類的完整定義與資料來源。

## 使用前要知道的事

- 這是歷史資料，不代表未來，也不是買賣建議。
- 數字的前提是「買了就一直持有」。中途進出的人，實際報酬可能差很多。
- 名單只有目前還掛牌的 ETF，已下市的不在裡面（存活者偏差）。

## 資料

證交所 ISIN 名單與開放資料、Yahoo Finance 含息還原價、加權指數（^TWII）。資料截止日寫在網站上方。

整個網站就是 `index.html` 加 `data.json`，所有計算都在瀏覽器裡完成。
